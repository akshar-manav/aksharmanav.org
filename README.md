# aksharmanav.org

Official multilingual website and publishing platform of Akshar Manav.

Akshar Manav's work began as an informal movement in 1981 and the organisation was formally registered in 1996. The platform will present its philosophy, work, history and public activity, and will provide a multilingual publishing system that can grow with the organisation.

## Current status

The product, rights and Joomla engineering foundations are established. A reproducible local Joomla 6.1.2 / PHP 8.4 / MySQL 8.4 environment has been proven on Windows, including successful local database and uploaded-media backup/restore rehearsal.

The project is now moving from infrastructure foundation into **information architecture, editorial workflow, visual design and the first real Joomla vertical slice**. Production deployment has not begun, and no production host has been selected.

For the fastest orientation, start with the [Website Project Hub](docs/PROJECT_HUB.md). It records the current state, project boundary, collaboration model and immediate next milestone.

To prepare the local environment, follow the [local development guide](docs/LOCAL_DEVELOPMENT.md). Local startup does not deploy or create external infrastructure.

## Repository boundary

This repository is for the `aksharmanav.org` website and publishing platform. It is **not** the operating repository for Akshar Manav's general organisational management, social-media operations, departments, events, outreach or internal administration. Approved organisational decisions and public content may become inputs to this website project.

## Authority and participation

Ajinkya Kinhikar is the current product owner and final website release authority. Akshar Manav's wider working model is intended to be decentralised, democratic and open to meaningful participation. Website contributions, translations, reviews and proposals should therefore be transparent and reviewable, with clear accountability for production releases.
